# Quickstart

Du spielst ein **Duo**: einen Reiter und (meist erst später) seinen Drachen. Alles Weitere steht im Reiter «Regeln».

## Würfeln

- **Probe:** Attribut + Fertigkeit = so viele W6. Jede **5 oder 6** ist ein Erfolg.
- **Nötige Erfolge:** leicht 1, normal 2, schwer 3, heldenhaft 4+.
- **Vorteil:** Erfolg schon ab 4. **Nachteil:** nur die 6 zählt. Beides zusammen hebt sich auf.
- **Patzer:** 0 Erfolge und mindestens eine 1: etwas geht schief.

## Dein Charakter

- Alle Attribute starten auf 1, alle Fertigkeiten auf 0. Dazu **24 EP** zum Steigern.
- Auf Stufe 1 höchstens Attribut 2 und Fertigkeit 1.
- Im Werkzeug: «Bearbeiten» zum Erstellen, «Charakterbogen» zum Spielen.

## Kampfrunde

1. **Initiative:** Tempo des Drachen + so viele W6, wie der Reiter Geschick hat. Höchster Wert beginnt.
2. **Manöver:** Bewegen, z. B. eine Zone steigen oder sinken.
3. **Angriff:** **entweder** Reiter **oder** Drache greift an, nie beide.
4. **Schaden:** Erfolge mindestens so hoch wie die Verteidigung = Treffer. Schaden = Grundschaden + jeder Erfolg darüber.

- **Zonen:** Unterwasser, Boden, Tief, Hoch, Wolken. Nahkampf nur in derselben Zone, Fernkampf auch eine Zone weiter.
- Wer **nach unten** angreift, hat Vorteil.
- Angriffe auf ein Duo treffen den Drachen. Den Reiter gezielt anzugreifen geht nur mit Nachteil.

## 0 Lebenspunkte

- Wer auf 0 LP fällt, ist kampfunfähig und würfelt jede Runde 1 W6:

| Wurf | Folge |
| --- | --- |
| 1 | +2 Wunden |
| 2–3 | +1 Wunde |
| 4–5 | nichts |
| 6 | wieder auf 1 LP |

- **3 Wunden = tot.** Ein Verbündeter kann stabilisieren (Verstand + Heilkunde).
- **Rettung:** 1× pro Tag kostet 1 Bindung, und Reiter oder Drache bleibt auf 1 LP statt auf 0 zu fallen.

## Bindung & Tag

- **Bindung** (0–20) gibt Extra-Würfel, wenn Reiter und Drache sich bei einer Probe helfen.
- **Spezialfähigkeiten** wirken 1× pro Tag.
- **Rast** (Nachtruhe): Fähigkeiten, Schüsse und Mut sind wieder voll. Wer 1 Proviant isst, heilt. Ohne Proviant: kein Heilen und −1 LP.
- **Wilde Drachen zähmen:** erst Geschick + Schleichen, dann Herz + Zähmen. Lieblingsfutter gibt Vorteil.
